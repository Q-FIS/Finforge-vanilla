# Decisions

The project's key decisions and why we made them. If a decision changes, edit
its entry and say what changed and why; don't delete it.

## D1. No module may share a name with a built-in Python module
The first plan had `types.py`, `numbers.py`, `chunk.py` and `trace.py`, and all
four are built-in Python modules. Running a file directly (`python src/rag/x.py`)
puts its folder first on Python's import path, so our file would replace the
built-in one for every library, and the crash would show up somewhere unrelated.
They are now `schema.py`, `amounts.py`, `chunking.py` and `failure_trace.py`.
`tests/test_module_names.py` fails if a new clash appears.

## D2. One project lead; reviews come from teammates and freshers
The project lead is the only CODEOWNER (contracts: `schema.py`, `config.py`,
`match.py`, `amounts.py`, `registry.py`, dependencies, `.github/`). There are no
separate team leads. A PR merges with: green CI + one approval from someone on
the same team (is it correct?) + one fresher sign-off (can they explain it?).
T1, T2 and E2 have the lightest load. They are the backups when an issue on the
critical path (parse, clean, chunk, embed) falls behind.

## D3. One LLM: Anthropic `claude-haiku-5-5`, through the API
Laptops can't run a 7-8B local model fast enough for ~1,200 calls per run cycle.
An API model also gives exact token counts from the provider. We use one model
for the whole project, because with 60 dev questions a two-model comparison
would mostly measure noise. The club shares one API key, read from the
`ANTHROPIC_API_KEY` environment variable and never committed. Every call is
cached on disk, so re-running a config costs nothing. Until GEN-01 lands,
everything runs on `FakeLLM` (`llm.fake: true`).

## D4. Corpus: Infosys, Asian Paints and Titan Company, FY2024 and FY2025
Three sectors (IT services, paints/consumer, jewellery/retail). Each has
listed subsidiaries and publishes standalone and consolidated statements, which
the entity and statement-basis questions need. We avoid banks and insurers:
their statements follow a different (RBI/IRDAI) format. If a report turns out
to have no text layer, E1 swaps in Larsen & Toubro or Dr. Reddy's.

## D5. Embedding models: `BAAI/bge-small-en-v1.5` (default) and `intfloat/e5-small-v2`
Both have 384 dimensions and a 512-token limit, and both run on a laptop CPU.
E5 needs the `query: ` / `passage: ` prefixes, which is what experiment E3
measures.

## D6. Names and conventions
- `FY2025` means April 2024 to March 2025.
- `doc_id` is `<company>_ar_fy<year>`, e.g. `infosys_ar_fy2025`.
- PDFs live at `data/pdfs/<doc_id>.pdf` and are never committed (the
  pre-commit hook blocks files over 1 MB).
- Page numbers are physical and 1-based (what a PDF viewer shows). The printed
  page number is stored separately as `Page.label`.
- Money in `Question.answer_value` is in absolute rupees (₹1,45,000 crore =
  1.45e12).

## D7. The test fixture is a synthetic report
`tests/fixtures/acme_ar_fy2025.pdf` is generated by `scripts/make_fixture_pdf.py`
for a made-up company. Because the script wrote it, the right answer is known
exactly (`acme_ar_fy2025.expected.json`), it has no copyright issues, and it
contains every hard case on purpose: two columns, ruled tables, `(1,234)`, `—`,
a running header, printed page numbers that differ from physical ones, and an
image-only page. Real-report fixtures get added once the corpus is downloaded.

## D8. A chunk is "relevant" only if it has the quote's figures too
Text overlap alone isn't enough: "Profit for the year 16,900 14,300" (standalone)
and "Profit for the year 18,200 15,400" (consolidated, the next page) share 60%
of their characters. `rag.match.is_relevant` needs half the quote's text AND
one of its figures; `on_page` (the question checker) needs 90% of the text and
all of its figures. The thresholds are defined once, in `match.py`.

## D9. The lead wrote every stub before day 1
Every public function exists with its final signature, a docstring and a fake
but valid return value, marked `STUB(<issue>)`. So the pipeline runs end to end
from the first day (`tests/test_skeleton.py`), and each builder's first PR
replaces part of their own stub. Gate 1 (day 5): every builder has opened a PR.

## D10. Tooling
Python 3.12 (`.python-version`), `uv` for packages with a committed `uv.lock`,
CPU-only PyTorch (the default Linux wheel bundles ~2 GB of GPU libraries),
`ruff` for formatting and linting (run by pre-commit and by CI from the same
locked version), `pytest`.
